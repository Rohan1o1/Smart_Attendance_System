Deploy checklist (Render)

- Set Root Directory to `server` (if server code is in `server/`).
- Build Command: `npm install` (or leave blank if Render runs install automatically).
- Start Command: `npm start` (uses `server/package.json` start script -> `node app.js`).
- Env vars to set in Render:
  - MONGODB_URI (use Atlas URI, include DB name: `/attendance_system?retryWrites=true&w=majority`)
  - JWT_SECRET
  - NODE_ENV=production
  - CLIENT_URL (optional)
  - ADMIN_EMAIL / ADMIN_PASSWORD (optional)
  - FACE_MODELS_URL or FACE_MODELS_PATH (if models hosted externally)
  - EMAIL_PASSWORD, REDIS_PASSWORD (if used)

Notes:
- Do NOT commit `.env` to repo; configure env vars in Render dashboard.
- If using native libs (`canvas`, `sharp`) consider Docker.
